# Labels

Steward applies these on a new repo. Surgeon does not backfill labels unless assigned.

Triage (GitHub Manager owns the states):

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`

Type:

- `bug`
- `enhancement`

Class (one per repo, on the repo or as a note in the first issue; do not stack):

- `class:go-cli`
- `class:node-bun`
- `class:python-tool`
- `class:docs-only`
